# KeyHaven brand assets

This directory is the canonical source for KeyHaven logos used by the application. Runtime paths begin with `/brand/` because Next.js serves files in `public/` from the site root.

## Wordmarks

- `logo.svg` and `logo.png`: sage typewriter with ink lettering for light surfaces
- `logo-dark.svg` and `logo-dark.png`: sage typewriter with ivory lettering for dark surfaces
- `logo-tagline.svg` and `logo-tagline.png`: light-surface logo with “Read deeply. Type naturally.”
- `logo-tagline-dark.svg` and `logo-tagline-dark.png`: dark-surface logo with tagline

The typewriter in each lockup is proportionally scaled and aligned to the height of the capital K. Prefer SVG in the application; PNG files are export-ready fallbacks.

## Marks and icons

- `logo-icon.svg` and `logo-icon.png`: sage typewriter mark
- `logo-icon-ink.svg` and `logo-icon-ink.png`: ink typewriter mark
- `logo-icon-ivory.svg` and `logo-icon-ivory.png`: ivory typewriter mark
- `favicon.ico` and `favicon-32.png`: browser icons
- `keyhaven-preview.png`: light and dark reference sheet

Do not reference copies in Downloads or temporary directories from application code.
